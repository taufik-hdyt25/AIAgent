Full Automation (GitHub & Deploy)

Otomatisasi deteksi issue, analisis AI, auto-fix & Draft PR, serta eksekusi deployment server.

Wajib untuk Auto-PR & Watcher
Dapatkan Personal Access Token (classic) dengan scope repo dari GitHub Token Settings.
GitHub Watcher (Saklar Utama) Mengecek issue baru di repo yang dipantau secara berkala. Jika dimatikan, Auto-Analyze dan Auto-Fix di bawah ikut berhenti. Cek manual via /checkissues tetap bisa dipakai.
1. Auto-Analyze Issue Saat issue baru terbuka di repo GitHub yang dipantau, AI otomatis mengambil detail issue, mendiagnosis akar masalah, dan mengirim laporan analisis ke Telegram.
2. Auto-Fix & Draft PR Otomatis AI otomatis membuat branch fix/issue-<no>, memperbaiki file kode yang bermasalah, melakukan commit, push, dan membuka Draft Pull Request di GitHub. Jika nonaktif, Anda tetap bisa menjalankannya via tombol 1-klik di Telegram.
Dapat dieksekusi via /deploy
Perintah terminal yang dijalankan saat Anda memicu deployment via chat Telegram (/deploy) atau tombol inline.
